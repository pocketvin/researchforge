## Outcome

The CATL 2024H1 product package no longer reads `reported_value`, fact `page` or
`evidence_text` from the filing registry. The registry now contains only reviewed document
identity, company and reporting-period metadata.

One company-independent Python extractor recovers exactly six metrics from the verified PDF's
native text layer. It detects consolidated statement boundaries, carries table context across
physical pages, resolves the current-period column and declared unit, joins wrapped rows,
normalizes with `Decimal`, and verifies that the evidence window is present on the recorded page.
No model participates in numerical extraction or promotion.

## Abstention evidence

Automated tests prove all-or-nothing refusal for:

- a missing target row;
- two conflicting matches for one metric;
- a header that does not resolve to the requested reporting period;
- conflicting unit declarations;
- no usable native text layer;
- official hash mismatch before parsing.

Parent-company statements are explicit context boundaries and cannot supply consolidated facts.
An extraction failure writes a schema-valid manifest with no Financial Fact output.

## Reproduction

```bash
uv run researchforge ingest-disclosure \
  --company cn_300750 \
  --period 2024H1 \
  --registry data/product/filing-catalog.json \
  --raw-root data/raw/product \
  --package-root data/product/packages/catl-2024h1 \
  --source-file data/raw/product/catl-2024h1.pdf

uv run pytest tests/ingestion/test_product_disclosure.py -q
uv run python scripts/validate_contracts.py
```

The first command succeeds only when the local ignored PDF matches the frozen official identity.
The committed derived package lets CI validate all schemas, hashes, locators and normalization
relationships without redistributing the source PDF.

## Bounded limitations

- Only the six frozen metrics are supported.
- Only consolidated native-text statements are promoted.
- Ambiguous or absent table, row, period column or unit causes abstention.
- OCR and scanned-only filings are outside Phase 2.
- This evidence proves CATL 2024H1. Cross-period and cross-company evidence belongs to Phase 3.
- This is engineering evidence, not real-human usefulness evidence.
