# ResearchForge V1.4 Demo Script / 演示脚本

## 中文（约 3 分钟）

1. 运行 `docker compose up -d --wait`，说明系统由 React、FastAPI 和 PostgreSQL 三个服务组成。
2. 在 Research 页选择研究模式、公司和报告期并提交。强调所有数字来自 API 的冻结事实，公式由 `Decimal` 确定性计算。
3. 展示 10 阶段 LangGraph 进度、执行摘要、财务快照、Claim—Fact—Evidence、反证搜索、限制和官方来源。
4. 打开 Skill Lab，读取受控实验。展示失败聚类、Experience、Candidate Skill Diff、Seed/Candidate Validation 配对和一次性 Final Test。
5. 明确结尾：这不是投资建议；真实用户价值尚未验证；模拟评审始终标注 `SIMULATED`；只有封闭 Final Test 达标才能写 `SUPPORTED`。

## English (about 3 minutes)

1. Start Docker Compose and identify the React, FastAPI, and PostgreSQL services.
2. Submit a mode, company, period, and question on Research. Explain that every number comes from frozen API facts and deterministic `Decimal` formulas.
3. Show the ten-stage LangGraph progress, executive summary, financial snapshot, Claim—Fact—Evidence links, counter-evidence, limitations, and official sources.
4. Open Skill Lab and load the controlled experiment. Show the failure cluster, Experience, Candidate Skill Diff, paired Seed/Candidate Validation, and one-time Final Test.
5. Close honestly: this is not investment advice; real-user value remains unvalidated; simulations are labeled `SIMULATED`; only a passing sealed Final Test can support `SUPPORTED`.
