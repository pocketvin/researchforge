# ResearchForge V1.3 → V1.4 Change Note

Status: accepted

V1.4 supersedes V1.3 for all new implementation and artifacts. V1.3 scope, schemas, examples, and the Git baseline commit remain immutable historical evidence.

## Why the Minor Version Changes

The project owner changed the completion definition after V1.3 was accepted. A three-person target-user pilot is replaced by three isolated AI simulations, while the project-level completion target now requires both a full engineering product and a supported sealed research result. This changes the meaning of success evidence and therefore requires a new minor contract version rather than an in-place patch.

## Added

- Eight persisted artifact contracts: Source Document, Calculation Record, Tool Record, Skill Version, Experience, Evolution Experiment, Retrieval Evaluation, and Simulated Usability Evaluation.
- Exact primary and contingency A-share experiment suites, with six target reports per company.
- OpenAI Responses API configuration, `store: false`, no built-in tools, and a USD 20 aggregate hard cap.
- One versioned contingency experiment after an unsupported primary result.
- Public-data rules that exclude full filing PDFs and uncertain-license raw payloads.

## Changed

- Active artifact version is `1.4.0`; V1.3 artifacts are not silently reinterpreted.
- G4 ends at **Full Engineering Product Ready**, not proof of real-user usefulness.
- Simulated sessions MUST use `evidence_label: SIMULATED` and `human_user_value_validated: false`.
- Project completion requires both Full Engineering Product Ready and Research Hypothesis Supported, followed by independent review PASS.
- Retrieval only unlocks pgvector when Recall@5 improves by at least 0.10, no new citation mismatch appears, and p95 latency stays within 2× the deterministic baseline.

## Preserved

- Five bounded product task modes.
- One single-agent LangGraph Research workflow.
- Plain-Python finance, retrieval, verifier, persistence semantics, and Evolution pipeline.
- Deterministic formulas, point-in-time provenance, split isolation, bounded Skill patches, and one-shot Final Test rules.
- No trading, investment advice, real-time market data, multi-agent system, or open-ended self-modification.

## Migration Rule

Any V1.3 artifact used by V1.4 must be copied into a new V1.4 artifact, revalidated against the V1.4 schema, assigned a new content hash, and linked to the preserved source artifact. Destructive or silent migration is prohibited.
