# ResearchForge V1.6 → V1.7 General Research Change Note

**Date:** 2026-09-05
**Authority:** RF-033
**Status:** Engineering implementation complete; owner acceptance pending

## Why this change exists

V1.6 proved that ResearchForge can resolve a public company, discover an official filing in CN/US/HK, recover six verified financial facts and produce an auditable run. Owner acceptance nevertheless rejected Release Freeze because the product still behaved like a narrow earnings-quality analyzer: answers were short and many reasonable company-research questions collapsed to the same cash-conversion analysis.

V1.7 changes the research layer, not the official-source trust boundary.

## Product contract

Default input remains company/ticker + optional market/period + natural-language question. The default autonomous mode is now `general`, which creates a `company_research` run.
The run must execute:

```text
Question Understanding
→ Skill Routing
→ Question-specific Research Plan
→ Official Filing / Verified Facts
→ Full-filing Evidence Retrieval
→ Deterministic Financial Calculations
→ Counter-evidence Search
→ Evidence-constrained Research Draft
→ Claim/Reference Validation
→ Research Result + Trace
```

The first six Skills are Company Overview, Earnings Change, Growth Analysis, Financial Health, Risk Analysis and Business Analysis.

## Evidence boundary

The existing six facts remain deterministic numerical truth. V1.7 additionally indexes native official filing text into bounded Evidence Chunks with document identity, source URI, section, page/character locator and content hash. Filing text is untrusted data and cannot provide instructions to the Agent.
A material V1.7 finding must cite only Evidence IDs selected by the current retrieval/counter-retrieval step. Fact IDs must refer to verified facts loaded for the same run. The language model may explain causes only when the supplied filing evidence directly supports that explanation; it may not fill gaps from memory.

## Result boundary

A successful V1.7 General Research result uses schema `1.7.0` and adds:

- `research_intent`
- question-specific `research_plan`
- 2–8 evidence-linked Claims, targeting 4–8 when evidence supports it
- `analysis_sections`
- `overall_judgment`
- `suggested_follow_ups`
- `evidence_coverage`

The V1.4/V1.5 schemas and reviewed evidence remain historical contracts and are not rewritten.

## Compatibility

`financial_snapshot` remains an explicit compatibility mode that uses the V1.6-style `filing_analysis` path and may reuse reviewed packages. General Research uses a separate versioned live Evidence package cache so stale six-fact-only packages cannot silently satisfy a V1.7 run.
