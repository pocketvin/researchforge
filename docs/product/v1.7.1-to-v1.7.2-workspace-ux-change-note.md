# ResearchForge V1.7.1 → V1.7.2 Workspace UX Change Note

**Date:** 2026-09-05
**Status:** Engineering complete; owner re-acceptance pending

## Why this patch exists

V1.7.1 fixed Research Synthesis quality. The next owner test judged the research result broadly acceptable but exposed six workspace problems: Suggested Follow-ups appeared inert, disclosure/audit sections had unclear hierarchy, Monitoring was hard to understand, Quality Lab had little normal-user value, its adoption arrows looked clickable when they were not, and switching pages discarded the current report with no history viewer.

## Product changes

- Suggested Follow-ups now directly create a new research run while preserving company, market and period context.
- A bounded recent-run endpoint lists persisted product `company_research` runs; the Web reopens Result, Facts, Evidence, Calculations and Trace without rerunning research.
- Research stays mounted while the user visits the methodology archive, so current work is not lost.
- Primary reading is conclusion → findings → deep analysis. Facts, calculations, supporting evidence, counter-evidence, future-review checklist and Trace are audit-on-demand.
- Monitoring is renamed “下一份财报重点看什么” and explicitly described as a future-review checklist, not an alerting service. Generic entries can be hidden.
- Quality Lab is demoted from primary navigation to the read-only “方法与实验” archive. Historical evidence remains intact. Inactive steps show no arrow; loaded steps have real navigation targets.
- The redundant single-item top “Research” tab is removed; the header is now brand-left / data-status-right, and the ResearchForge brand remains the home action.
- Run IDs and raw technical enums are demoted in favor of company/intent context and readable Chinese labels.

## Persistence boundary

History does not create a second database or duplicate research content. It lists existing immutable product Run manifests and restores the already persisted artifact families. CI/reviewed-cache `financial_snapshot` runs are excluded from normal research history.
