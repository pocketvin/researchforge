# ResearchForge Web Research Workspace

## 信息与视觉

- 报告先回答研究问题，页面明确公司、报告期、资料截止时间与运行状态。
- 默认阅读层不堆 node/span/hash/JSON。正文至少 15px，辅助文案至少 12px；舒适行宽、明显层级。
- 桌面报告主栏 + 原文侧栏；窄屏侧栏变为可关闭全屏证据抽屉。保留滚动位置。
- 采用克制的浅色纸面、深色正文、少量语义色。卡片只承载独立信息，不做装饰性 KPI Dashboard。
- 实际数据缺失时显示缺失原因。没有比较期不得生成趋势箭头、增长率或趋势图。
- 模型判断、规范财务事实、原生解析候选、语义复核、独立评测必须分别标识。

## 核心交互

- Claim → 引用片段 → 表格/页面 → 原始财报。一两次点击能抵达实际来源，不只是 Evidence ID。
- 表格保持原始行列和合并单元格；单位/表头/脚注一起展示。可滚动但不能裁掉数字。
- 原页图像是真实 PDF 渲染，不用重绘财报或模型生成图片冒充来源。
- 默认 Trace 展示“正在查什么、读到什么、假设有什么变化、为什么停止”；操作详情按需展开。
- 工程审计展示真实参数、输出、时间、失败和证据ID；绝不生成隐藏 CoT。
- 无虚假进度条；PDF 处理页数可以按实际 done/total 展示，代理研究不编造完成百分比。
- 用户切换历史记录不能让旧请求覆盖新结果；刷新后能继续读取运行状态；关闭流不等于取消。
- Loading、错误、取消、无资料和模型不可用都有明确文案与恢复入口。

## 验证

- 用真实后端产物验证来源抽屉、表格、页面图像、SSE更新、历史恢复和取消。
- 检查键盘焦点、按钮可访问名称、360px窄屏与桌面布局、长中文和空数据。
- 美观不能替代准确；模型复核通过不等于报告绝对正确，更不能展示未测的独立质量分。
